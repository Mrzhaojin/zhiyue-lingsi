## M1.5a 变更明细

### 1. 领域层独立

- `src/data/models.ts` → `src/domain/models.ts`（git mv，保留历史）；
- 15 处 import 全部改为 `domain/models`；
- 新增 `src/domain/errors.ts`：`AppError` + 错误码 + `toAppError`。

### 2. 拆掉 750 行门面

`src/data/api.ts` 按领域拆为 `src/data/core/` 12 个模块：

| 模块 | 职责 |
|---|---|
| `shared.ts` | `now` / `data()` 快照读取 |
| `users.ts` | 当前用户、身份绑定、资料 |
| `snapshot.ts` | 快照、导出/导入、体积 |
| `library.ts` | 书、标签、书架 |
| `posts.ts` | 帖子与评论 |
| `notes.ts` | 笔记、按作者筛选、按标签聚合 |
| `interactions.ts` | 点赞/收藏（复合键幂等） |
| `learning.ts` | 生词本 |
| `reading.ts` | 阅读进度与历史 |
| `notifications.ts` | 通知 |
| `admin.ts` | 管理配置 |
| `assistant.ts` | AI 会话、消息、赏析记录 |

`src/data/api.ts` 现在只剩兼容导出（`@deprecated`），`data/db.ts` 保持不变，30 个页面零改动。

### 3. 仓储接口与本地实现

- `src/data/repositories/types.ts`：`PostRepository` / `NoteRepository` / `InteractionRepository` / `BookRepository` / `ShelfRepository` / `CommentRepository` / `ProfileRepository` / `ReadingRepository` / `AssistantRepository` / `BackupRepository` / `AdminRepository`；
- 全部方法返回 `Promise`，分页统一 `cursor`，错误用 `AppError`；
- `src/data/repositories/local/index.ts`：基于 core 的本地实现；
- `src/data/repositories/index.ts`：`repositories` 单例（M2 按运行时切 Remote）。

### 4. 契约测试与缺陷修复

新增 8 条测试（合计 21）：

- 帖子分页：游标不重复；
- 更新不存在 → `NOT_FOUND`；空标题 → `VALIDATION_ERROR`；
- 点赞切换幂等、计数回到原值；
- 笔记保存/读取/删除；评论按帖子读取；
- 书库语言过滤；导出回导一致。

测试发现并修复的真实缺陷：同毫秒创建时排序缺少 id tie-breaker，导致游标跨页重复。已改为「分数降序 + id 降序」的确定性排序。

- 计数无对账任务。
