# ADR-0004：笔记发布为引用型帖子

- 状态：已采纳（设计阶段）
- 日期：2026-11-27
- 关联：领域模型 D1/D2；数据模型 §2.5

## 背景

当前发布笔记的实现是：保存笔记后，复制标题与正文新建一条帖子。
结果是同一内容存两份：编辑笔记不会更新帖子，统计（点赞/评论）也分叉。
同时笔记本身也能被点赞/收藏，与帖子的互动口径不一致。

## 决策

1. `posts` 增加 `kind`（`original`/`note`）与 `note_id`；`kind='note'` 时正文不落库，读取时 join 笔记；
2. 笔记增加 `published_post_id`，一对一；发布幂等（已存在则复用）；
3. 取消发布 = 笔记回草稿 + 帖子软删；删除笔记 = 帖子一并软删；
4. 互动（点赞/收藏）与评论只针对帖子，不针对笔记。

## 后果

- 单一真相：编辑笔记后社区内容自动一致；
- 统计口径统一；查询需要 join（50 用户规模可接受）；
- 需要一次历史数据关联迁移（按作者+标题+正文匹配），并处理多条命中；
- 笔记列表的点赞数改为读取其发布帖子的计数。

## 备选方案

- **保持复制**：实现简单，但双写与统计分叉会持续产生 bug，放弃。
- **只做笔记、不发布到社区**：削弱产品闭环，与现有功能冲突，放弃。
