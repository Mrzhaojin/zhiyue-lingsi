# ADR-0006：RAG 采用混合检索 + 强制引用

- 状态：已采纳（设计阶段）
- 日期：2026-11-27
- 关联：需求 Q4（A + RAG）、FR-E10~E12；设计 `docs/design/RAG.md`

## 背景

当前 AI 只能凭空回答：不注入书库内容，也没有引用。
用户问“这本书第几章提到 X”时，模型无法给出可信答案。

## 决策

1. 语料 = 公版/授权书章节 + 已发布笔记；草稿与私密内容不入索引；
2. 切分 300–450 tokens，重叠 60；每块保留定位与 hash；
3. 检索用「向量 top30 + 关键词 top30 → RRF 融合 → top8」，可选 rerank；
4. 生成必须带引用；引用片段必须是块文本子串，否则丢弃并标记未接地；
5. 无命中（<2 条）时明确拒答，不调用模型编造；
6. 30 条黄金集，指标：Recall@8 ≥0.8、引用准确率 ≥0.9、拒答准确率 ≥0.9。

## 后果

- 需要 embedding 供应商与索引流水线；
- 回答延迟增加（检索 + 生成），首 token P95 目标 ≤2s；
- 引用让回答可验证，也便于面试/评审演示；
- 本地模式没有 BFF 与向量服务，明确降级为普通问答。

## 备选方案

- **纯向量检索**：对专有名词/短查询弱，放弃。
- **纯关键词**：语义召回差，放弃。
- **把整本书塞进 prompt**：成本高、超上下文、不可引用，放弃。
